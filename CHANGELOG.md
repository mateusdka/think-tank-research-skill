# Changelog

Todas as mudanças relevantes deste projeto são registradas aqui.

## 0.2.1 (2026-09-02)

### Adicionado

- protocolo editorial com checagem de consistência de idioma e proibição de travessão separador em português;
- primeira homologação ponta a ponta em ChatGPT web e claude.ai (plano Free), com descoberta, escolha de modo e gates observados.

### Alterado

- README atualiza o estado de maturidade: ChatGPT web e Claude.ai homologados; Hermes validado localmente; Codex e Claude Code pendentes de homologação.

## 0.2.0 (2026-09-02)

### Adicionado

- modos de execução para workspace persistente, sandbox e sessão única;
- adapters para Hermes, Codex, Claude Code e plataformas web;
- gates separados de revisão de evidências e revisão editorial anti-slop;
- exemplos de pesquisa simples e relatório estratégico;
- validação estrutural e de privacidade;
- geração reprodutível do pacote `.zip`, manifesto e checksum.

### Alterado

- núcleo metodológico desacoplado dos nomes de ferramentas do Hermes;
- README reorganizado pelo problema resolvido e pela compatibilidade real;
- templates ampliados para registrar modo de execução e gates de qualidade.

## 0.1.0 (2026-08-19)

- primeira versão pública da skill de pesquisa multi-persona.
